# 书源适配

书源采用两层结构：

1. Android 原生引擎（`android/.../booksource/`）解析 Legado 规则并执行网络请求。
2. Flutter 适配层（`lib/book_sources/`）负责 JSON 校验、来源存储、整数书籍 ID、章节 ID、离线缓存与现有阅读器格式转换。

Flutter 不解析 `ruleSearch`、`ruleBookInfo`、`ruleToc` 或 `ruleContent`。新增规则支持应修改原生解析器，避免形成第二套书源规则。

## 已接入

- 单个书源对象、书源数组、`sources` / `bookSources` 包装对象导入，书源总量上限 10000 个。
- 从 `http` / `https` 链接直接下载书源 JSON 导入，单文件上限 128 MB；返回网页的链接会被拒绝。
- 文字类型 `bookSourceType: 0`；文件类型 `3` 目前按文字规则尝试解析。
- 搜索、详情、目录、正文；正文规则返回多条结果时全部拼接，`nextContentUrl` 支持并列多页与串行翻页（最多 100 页），下一页命中下一章时熔断；正文开头与目录重复的章节标题会被剥离，由阅读器单独渲染章节头。正文提取规则升级后，联网阅读会忽略旧版缓存重新抓取一次，离线仍可读旧缓存。
- `nextTocUrl` 只返回一个有效地址时逐页跟随；返回多个时按给定顺序读取，不再跟随后续页内的分页链接。允许第一页只有分页导航，总计最多读取 20 页。`chapterList` 的 `+` 为正序、`-` 为整份目录倒序；同一章节地址跨页重复只保留一次，无地址的分卷行不会因地址为空而丢失。
- `ruleToc.isVolume` 标记分卷；卷前章节保持未分卷。`isVip` 为真且 `isPay` 不为真时，目录显示 VIP，不阻止尝试读取；离线快照保留该标记。`formatJs` 在整份目录排序、去重后按行格式化标题，可使用 `title`、从 1 开始的 `index`、本次目录共享的 `gInt`（初始 0），以及 `chapter` 的 `index`（从 0 开始）、`title`、`url`、`baseUrl`、`bookUrl`、`tag`、`isVolume`、`isVip`、`isPay` 属性。脚本出错或返回 `null` / `undefined` 时保留原题，不影响其他章节；未实现 Legado `BookChapter` 的全部原生方法。
- 正文按分页地址而非段落文字去重：重定向到已读页或下一章时不追加正文，不会误删不同页中内容相同的段落。带请求选项的分页地址区分不同的 POST 请求体。
- 搜索并发查询当前范围内已启用且支持搜索的书源，结果渐进显示；单个来源超时不会中断其他来源，新搜索或离开搜索页会取消上一轮未完成请求。
- 搜索范围可切换为全部书源、一个或多个分组，或指定书源；范围只影响导入书源，不影响轻小说文库结果。范围会持久化，并在下一次搜索时生效。
- 发现页读取已启用书源的 `exploreUrl`，支持 Legado 发现入口、分类、筛选条件、分页、`exploreUrl` 联合规则和发现动作；未填写 `exploreUrl` 的来源仍可用于搜索。
- 发现页默认直接展示榜单：优先排列名称或地址包含起点、番茄的书源，自动读取其榜单入口并加载书籍，不再先显示书源卡片列表；其他带发现地址的书源作为补充来源。
- 换源在所选范围内的已启用来源中检索同名书，可开启/关闭作者校验；排除与当前书籍地址和来源都相同的候选，按书源自定义顺序、来源名称、书名排序。新目录成功加载且非空后才切换，保留书籍 ID 和原作者；自定义封面优先，否则采用新书源封面。
- 文字书源校验：管理页右上角选「校验当前列表」，或多选后选「校验所选书源」。按源内 `ruleSearch.checkKeyWord`（无有效值时用输入词）搜索，检查首个结果的详情、目录和第一章正文。分别报告通过、未命中、跳过或具体失败阶段；不会写入书架、分组或启用状态。停止或关闭弹层后不再发起下一阶段，已发出的请求可能执行至返回或超时。校验不包含发现分支、域名探测、后台服务或自动失效分组。
- 书源管理支持按名称、链接、分组搜索，按启用状态/分组筛选，按导入顺序/名称/最近更新/启用状态排序，以及多选批量启用、停用、删除、导出和加入/移出分组。
- 点书源行可展开发现区，按 Legado 的 6 列弹性布局排列分类、榜单、筛选条件、文本输入、开关和脚本按钮；点分类查看书籍和翻页，筛选值会带入发现请求；一次展开一个书源。编辑、登录等操作仍在行尾「⋯」中，支持登录的书源会在展开区显示登录状态和入口，底部「发现」的官网榜单不受影响。
- 单个书源可编辑名称、分组、搜索地址、发现地址、启用状态和发现开关；源地址作为书源身份保持不变，其他未展示的 Legado 字段继续原样保留。
- CSS/jsoup 选择器、`tag.` / `class.` / `id.` 写法，以及 `@text` / `@html` / 属性提取。普通元素规则先在每个父节点内匹配，再分别按从 0 开始的索引筛选：`tag.a.0:-1` 选首尾，`tag.a!0:-1` 排除首尾。旧式写法中的冒号分隔多个位置，不表示连续区间。
- 方括号支持按指定顺序选取、排除和闭区间：`tag.a[2,0]` 先取第三个再取第一个，`tag.a[!0:2]` 排除前三个，`tag.a[-1:0]` 倒序，`tag.a[::2]` 隔一个取一个。省略选择器时（如 `tag.section@[0]`）按直接子元素筛选。普通属性选择器（如 `a[data-id=2]`）仍由 jsoup 处理；显式 `@css:` 和 XPath 不套用这套元素索引。
- JSONPath（`$.`、`@json:`）、XPath（`//`、`@xpath:`，含 `//a/@href` 属性轴）、正则（`@regex:`）和 JavaScript（`@js:`）；JS 规则返回数组时会逐项展开，避免多段正文或多个下一页地址只取到第一项。
- `jsLib` 支持内联 JavaScript，以及 `{"名称":"https://..."}` 形式的远程脚本映射；远程脚本会在当前进程内缓存，加载失败时显示具体行和该行代码。
- `{{key}}`、`{{page}}`、`{{baseUrl}}` 以及通用 `{{JS 表达式}}`。
- Android 文字书源的搜索和发现共用分页判断：支持 `{{ page }}`、`{{(page - 1) * 20}}`、引用全局 `page` 的 `@js:` / `<js>` 地址，以及 `<首页,后续页>` 候选写法。页码从 1 开始，候选不足时沿用最后一项；只有有限候选且已用尽时，不再提示下一页。每页不足 10 本仍可翻页，空列表或响应明确表示末页时停止。判断脚本能否翻页不会执行脚本。
- 请求头、POST 表单/JSON、Cookie、编码检测；搜索地址支持多行回退。
- 书源封面和正文插图通过原生桥加载，复用书源请求头与 Cookie；正文插图可离线缓存。
- `java.get` / `java.post` 返回带 `body()`、`statusCode`、`url`、`headers()` 的响应对象。
- 表单登录：解析 `loginUi`（含 `@js:`、`<js>` 动态表单）和 `loginUrl`，支持 `text`、`password`、`select`、`toggle`、`button` 行。搜索、详情、目录、正文、封面和插图共用该书源的登录状态。原生 HTTP 请求按书源和目标来源（协议、主机、端口）隔离 Cookie，并匹配路径、有效期和 `Secure`；不会把书源登录头自动发给外站图片地址。
- `enabledCookieJar: false` 关闭自动接收响应的 `Set-Cookie`，不禁用显式登录 Cookie；启用时也接收各跳重定向的 Cookie。单次 URL 选项中的 Cookie 覆盖同名值，不丢弃其他已保存的 Cookie。
- 登录或退出后，当前书源的封面、插图和失败重试缓存失效，其他书源及已下载的离线文件不变。退出前已经发出的图片请求不能通过迟到的 `Set-Cookie` 恢复该会话。
- 登录信息、登录 Header 和 Cookie 使用 Android Keystore 加密保存；书源管理页的更多菜单可登录或退出登录，书源展开的发现区会显示当前登录状态并提供登录入口。
- 应用内 WebView 网页登录：当书源有 `loginUrl` 但没有可解析的 `loginUi` 时，可打开登录页完成账号密码、验证码和网页内跳转。支持读取 Cookie 属性的系统 WebView 会读取书源站点根路径、书源配置路径、同源登录地址及点击「完成」时的同源页面，保留 Cookie 的路径限制。例如 `Path=/reader` 的 Cookie 可用于 `/reader/chapter`，但不会发给 `/cover`。书源标识不是网址时以登录站点为准。
- 旧版 WebView 无法提供路径属性时，只从根路径回收 Cookie，不覆盖已有的非根路径 Cookie。不会遍历第三方登录站点或任意中间页面收集凭据，也不保存网页中输入的账号密码。只在其他路径或第三方域签发凭据、且不向书源站点回写的登录方式仍可能不可用。
- `loginCheckJs` 会在搜索、发现、详情、目录和正文响应后执行，可读取 `result.body()`、`result.url`、`result.statusCode` 和 `source.getLoginHeader()`，并通过 `source.putLoginHeader()`、`java.connect()` 刷新登录 Header 或重新请求；书源更多菜单提供“运行登录检测”手动执行一次。

漫画、音频、视频及下载型来源不在文字书源校验范围内。单源菜单的「调试已保存规则」可按手动输入的关键词检查解析链路，与登录检测分开。网页登录暂不完整支持 WebView 弹窗/多窗口、部分扫码或依赖外部 App 的回调；`loginCheckJs` 兼容 Legado 的“执行脚本并修正响应”语义，但不同书源不一定会返回统一的登录成功/失效字段，因此“运行登录检测”成功只表示脚本已执行，不能保证所有来源都能明确判断账号状态。

脚本引擎使用 Rhino 1.8.1，与参考 Legado 实现一致，但仍不支持部分 ES2015+ 语法（例如 `class`、`async/await`、`f(...args)` 展开调用、对象剩余/展开解构）。使用这些语法的 `jsLib` 会读取失败，并在错误信息中显示具体行号与该行代码；这不是登录问题。

## 官网榜单（发现页直连）

发现页直接加载起点、番茄、七猫和书旗的官方榜单。按榜单和分类缓存首页五分钟，下拉刷新会重新请求。翻页按书籍 ID 去重，整页重复时结束翻页。

在默认搜索框输入书名后，应用自动并行查询起点、番茄、七猫、书旗、轻小说文库和已启用书源。官方命中优先显示，同书名同作者合并。某站返回错误时，列表仍显示其他来源的命中。手选书源或分组时仅搜索所选范围。

- `起点`：9 个榜单，接口为移动站 `/webcommon/rank/*list`（桌面站由 WAF 拦截）；每页 20 本，用 `pageNum` 翻页。
- `番茄`：推荐榜与更新榜，接口为 `/api/rank/recommend/list`、`/api/rank/recent/update/list`；更新榜用 offset 翻页。

点击榜单书籍直接进入官方详情页：封面、书名、作者、标签、简介、目录和状态来自官网 SSR，起点还会显示字数。正文只提供免费章节试读；起点 VIP 章节（`vipStatus=1`）和番茄锁定章节（`isChapterLock=true`）会提示换源。番茄免费章节正文使用随机字体把部分汉字映射到私用区，按 `assets/book_sources/fanqie_font_map.json` 还原；字体文件变化时需要重新生成该映射。

番茄关键词搜索走无需签名的 `/api/author/search/search_book/v0` 列表接口（官网使用的 v1 需字节 `a_bogus`/`msToken` 签名，裸请求只会得到 HTTP 200 空正文）；v0 列表里的书名/作者/简介是私用区字体混淆，按独立的 `assets/book_sources/fanqie_search_font_map.json` 还原，个别未覆盖字符再回退 `/api/book/info` 明文。该映射与榜单/书库字体都不是同一套，字体轮换后需重新生成；未覆盖时自动回退，不影响正确性。

旧版本曾把起点/番茄作为内置书源写入书源库；`BookSourceRepository.builtinSourcesVersion` 升到 `4` 后，升级会清理这两个旧内置来源，`assets/book_sources/builtin_sources.json` 保持为空。

## 书籍封面

- 在图书详情右上角选择「更换封面」，或长按封面。有图时轻点仍为查看大图。可以选手机图片、输入 HTTP(S) 图片地址、使用默认文字封面，或恢复原封面。
- 手机选图保存在指定的本机图集，其他书可复用。删除图集不会删除已经选作书籍封面的图片。跨书源选图也会固定一份本机图片，不会切换正文、目录或阅读进度。
- 打开选图面板才会按书名、作者和启用范围读取候选；范围内候选不足时补搜，可停止或重新搜索。选图范围独立于换源范围，支持全部、分组和指定书源。离线时只读已缓存的候选图片。
- 网络封面的磁盘缓存上限为 96 MiB、1024 张，系统可以回收。书架优先用缓存；同一书源轮换封面链接后可回退该书旧图，详情联网成功后使用新图。书源会话变更会使对应书源缓存失效。自选封面和图集不在这个缓存目录内。

## 数据位置

- 书源：应用支持目录 `/wenku8-book-sources-v1/sources.json`
- 搜索范围：同目录 `/search_scope.json`
- 书源书籍身份：同目录 `/identities.json`
- 书源书籍 ID：`0x50000000` 到 `0x5FFFFFFF`
- 书单待匹配占位书 ID：`0x40000000` 到 `0x4FFFFFFF`；导入后先加入书架，点开时匹配书源并替换
- 本地导入书籍 ID 从 `0x60000000` 开始
- 登录信息、登录 Header、Cookie：Android `SharedPreferences` 中由 Android Keystore 加密的密文；旧版明文变量会在首次读取时自动迁移并删除明文

## 验证

Android 私有开发树的分页回归（从 `android` 目录运行）：

```powershell
.\gradlew.bat :app:testDebugUnitTest --tests '*BookSource*Test'
```

`BookSourceUrlRuleTest` 对照 Legado `AnalyzeUrlPagingTest` 的分页语法及反例；`BookSourcePagingFlowTest` 使用本机 HTTP 固定响应，不依赖在线书源或账号，校验短页继续、末页停止，以及搜索结果进入详情、目录和正文的请求顺序。

`BookSourceChapterPagingTest` 校验串行与并列目录、跨页章节顺序、重定向和下一章边界。

无 Android 原生构建环境时，至少检查：

```powershell
flutter analyze
flutter test
```

并在一台 Android 设备上导入一个文字书源，分别验证搜索、详情、目录、正文和断网后的已缓存章节。

## 安全边界

书源规则中的 JavaScript 与 Legado 一样可以访问 Java 类并发起网络请求；应用也为用户书源放开了 HTTP。只应导入可信来源，不要把未知书源当作纯数据文件处理。
