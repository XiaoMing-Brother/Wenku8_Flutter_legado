# 文库图标

图标使用已确认的黑白人物剪影：闭眼侧脸与展开的书页，搭配白色底色。

`app-icon-source.png` 是选定的原图，保留完整尺寸和材质，不重绘人物。`design-source.json` 保存底色、源文件名和图案比例。`app-icon.png` 是应用内使用的 512 像素版本，各平台启动图标由同一原图缩放生成。

更新原图后，需要同步重新导出 Android 自适应／主题图标、常规启动图标、iOS 各尺寸、HarmonyOS 图标和 `app-icon.png`。常规图标直接缩放原图；自适应图标从原图提取同一人物，并预留圆形裁切安全区。旧的 `app-icon.svg` 不再参与生成。
